# Security

This project uses the device's unencrypted LAN control protocol. Use it only on a trusted network, with no public port forwarding to the light.

Do not post tokens, private keys, actual device identifiers or desktop images in public issues. Use GitHub's private vulnerability-reporting feature when available. Otherwise, open an issue requesting a private reporting channel without including exploit details or private data.

Supported maintenance target: the latest source on `main`. Other devices and firmware revisions require their own validation.
